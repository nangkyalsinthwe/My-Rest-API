# My REST API

A RESTful backend API built with **Node.js**, **Express**, **MongoDB**, and **JSON Web Tokens (JWT)** for authentication and CRUD operations, deployed on **Render**.

- **Live Base URL:** `https://my-rest-api-lq82.onrender.com`
- **API Prefix:** `https://my-rest-api-lq82.onrender.com/api`

> **Note:** Hosted on Render's free tier — the first request after a period of inactivity may take ~30–50 seconds to wake up the server.

## ✨ Features

- **RESTful CRUD Endpoints:** Clean HTTP routes under `/api` supporting `GET`, `POST`, `PUT`/`PATCH`, and `DELETE`.
- **JWT Authentication & Authorization:** Protects private routes using Bearer tokens (`Authorization: Bearer <token>`).
- **MongoDB Integration:** Connects to MongoDB Atlas via `MONGO_URI` for persistent data storage.
- **Environment Configuration:** Uses `.env` variables (with `.env.example` included) to keep credentials and secrets secure.
